Personal project

SKU

From an Excel spreadsheet to an inventory with printable QR labels and a page for each product.

TypeApp
Date2026-07
StatusIn development
FieldCommerce
Built withCodex and Claude Code

SKU takes an Excel spreadsheet of products and turns it into three things in one pass: a unique code for each product, a printable label with its QR code, and a searchable inventory. Each product also gets its own web page, so scanning the label stuck on the box goes straight to the page for what is inside.

It is the most recent project of the set and the one that looks most like a working tool rather than an experiment: it solves a concrete warehouse problem, not a technical question.

It did not stay an idea. Each school sees only its own inventory, behind a login. Labels come out at 20×50 mm in both orientations, with a layout that fits them on the sheet with no waste. And there is a command to test the database connection without redeploying: that last part comes from someone who got tired of debugging blind.
